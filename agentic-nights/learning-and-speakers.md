# Learning resource and speaker kit

The shared course and speaker materials that make every Global AI Night part of one worldwide series.

## Learning resource: Agent Framework 101

[Agent Framework 101: Build your first agent](https://globalai.community/learn/agent-framework-101) is a free, 90-minute beginner course where attendees build a Python event assistant with Microsoft Agent Framework.

Over 5 modules, attendees connect to Learn Models, build an agent, add a tool, keep conversation context, and test their agent. Completing every module check and the final test earns 500 points and a certificate.

What organizers need to know:

- **Prerequisites:** basic Python, Python 3.10 or newer, a code editor, and a terminal. No previous agent experience needed.
- **AI credits are included.** Attendees get their own API key and token allowance, so nobody needs to bring a provider API key.
- **The timer starts on activation.** Activating AI access starts a 180-minute window that does not pause, even if the browser closes. Attendees should set up Python first and activate only when ready to build.
- **Extra access needs approval.** Attendees can request more time or tokens, but an organizer must approve it.
- **No repo to clone.** Attendees create each file from the course examples.

## Speaker kit

Use the official PowerPoint template and speaker card so every Global AI Night looks like part of one worldwide series.

**PowerPoint template.** [Download the Global AI Nights PowerPoint template](/global-ai-nights-template.pptx) and share it with all your speakers ahead of time. Please keep:

- The Global AI Nights intro slide at the start of the evening
- Your chapter logo and name in the marked space
- The closing slide with the hashtags and the Agent Framework 101 link

**Speaker card.** Fill in each speaker's name, photo, talk title, and your event date, then share it on your social channels and event page in the run-up to your Night. The speaker card download is still to be added.
