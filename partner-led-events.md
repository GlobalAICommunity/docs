# Partner-led opportunities

Partner-led opportunities are focused programs created with Global AI Community partners. They give chapters access to relevant technical content, speakers, and experiences while keeping local community needs at the center.

Participation details, available locations, and organizer requirements are shared when each opportunity opens.

## GitHub Dev Day

GitHub Dev Day is a partner-led developer event delivered with participating Global AI chapters.

The event focuses on practical developer learning and community engagement around GitHub technologies. Global AI Community and GitHub will share the event format, content, branding, eligible locations, and organizer guidance directly with participating chapters.

::: info Participation
GitHub Dev Day is not part of the seasonal calendar. Chapters should wait for an invitation or application announcement before planning an event.
:::
